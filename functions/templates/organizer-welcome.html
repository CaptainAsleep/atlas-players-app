Thanks for joining Atlas as an event organizer. You run events at fields and sites you don’t own, so you add the venue on each event, and Atlas handles the booking, payment and check-in side. Here’s how to get your first event live.

1
Set up payouts

Paid events need a payout account first. Open Payouts in the app and connect Stripe — ticket sales go to your own Stripe account. It only takes a few minutes, and a free event doesn’t need it.

2
Create your event

Open Events and start a new one. Add a title, date, time, price and capacity, plus a banner if you have one, and set a minimum age if the event needs it. Paste in your own waiver text so players can sign it as part of booking. For the venue, type in the name and address, or search the Atlas field directory to copy a field’s details and save typing. Copying a field’s details doesn’t mean that field has agreed to host you.

3
Publish when you’re ready

Nothing shows to players until you publish. Once it’s live, players can find your event in the Atlas app, then book and pay in one step.

4
Run the day

Your event page shows the roster as people book. On the day, use check-in to scan players in or check them in by hand, and keep an eye on waiver signatures from the same place.

Good to know
If you cancel an event, players receive a voucher for a future Atlas event — it doesn’t refund them automatically. Worth knowing before you sell tickets.
